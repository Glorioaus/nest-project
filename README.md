## 项目描述

[Nest](https://github.com/nestjs/nest) 框架 JavaScript 启动项目模板。

## 安装

```bash
$ npm install
```

## 运行应用

```bash
# 开发模式
$ npm run start

# 监听模式
$ npm run start:dev
```

## 测试

```bash
# 单元测试
$ npm run test

# 端到端测试
$ npm run test:e2e

# 测试覆盖率
$ npm run test:cov
```
